RADBRIDGE CANONICAL FEATURE MANIFEST
====================================

Purpose:
Prevent previously accepted RadBridge functionality from disappearing
during future source changes, builds, canary validation, or deployment.

CANONICAL RULES
---------------
1. One canonical source line only.
2. New development must start from current CANONICAL_HEAD.
3. Never build/deploy from an older snapshot.
4. Canary images must be built from canonical source only.
5. Missing accepted feature => STOP before build/deploy.
6. Historical code may be reconciled into canonical source, never replace it wholesale.
