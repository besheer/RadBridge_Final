RIS v5.27.4.1 Sidebar Menu Search

Adds:
- Search field at the top of the left sidebar.
- Instant filtering of every visible menu link.
- Section headings automatically hide when they have no matching items.
- Search works with English/Arabic visible labels and route text.
- Enter opens the first matching result.
- Escape or X clears search.
- Executive Analytics is now explicitly listed under Management when the user has analytics.executive.view.
- Existing permissions still control what can be found: search never exposes hidden unauthorized modules.
- Existing dashboards and navigation remain unchanged.
