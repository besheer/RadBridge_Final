RIS Web v5.4 Bilingual Procedure Catalog

Adds:
- 222 bilingual starter radiology procedures (English + Arabic).
- Modalities: DX, CT, MR, US, MG, RF, PX/IO dental, NM, PT/PET, OT/interventional.
- Procedure fields: Code, English Name, Arabic Name, Category, Modality, Body Part, Duration, Contrast, Base Price.
- Import/Export CSV includes Arabic name and category.
- Existing procedure prices are preserved during upgrade; newly added procedures default to 0 price.
- Order/appointment selectors show Arabic names when Arabic UI is selected.
- Existing v5.3 accounting, receivables, delivery tracking, calendar, attachments and professional UI retained.

The catalog is deliberately extensible: hospitals may have local protocols, combinations, naming conventions and special studies, so admins can add/import additional procedures without code changes.
