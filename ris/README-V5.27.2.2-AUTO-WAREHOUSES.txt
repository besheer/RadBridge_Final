RIS v5.27.2.2 Auto Branch Warehouses

Adds:
- One-click Auto Create Warehouses From Branches.
- Creates MAIN only when missing.
- Creates one BRANCH warehouse for each active Branch missing a warehouse.
- Existing warehouses are preserved, never duplicated or overwritten.
- Existing branch warehouses with no parent are linked to MAIN.
- Per-branch Create Warehouse button.
- Nursing no-warehouse warning offers Create Branch Warehouse Now for inventory managers.

All v5.27.2.1 Nursing Extra Consumables and prior functionality are preserved.
