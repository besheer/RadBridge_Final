# Technician and nursing worklist filters

Adds patient/ accession exact searches, modality, scoped room/device selectors, open/closed-now device availability, exam/PACS status, clinical history and attachments. Nursing also filters confirmed consumables; this is explicitly consumables confirmation, not a new assertion that patient preparation is complete. Existing priority/date/free text searches and technician correction queues remain available. An explicit exam status can search completed examinations; filters do not grant report access or alter an exam transition.

Saved searches reuse SavedSearchFilter, scoped by current user and page key (TECHNICIAN or NURSING). Existing save/apply/default/rename/delete routes are reused. These pages now require their worklist permission, active user and a dedicated session CSRF token for mutations. Filters store only whitelisted keys. Defaults redirect an empty worklist request to the user's selected filter. Any explicit query takes priority. Clear filters uses clear_filters=1 to bypass the default without deleting it. Clearing/deleting preferences does not alter clinical scope.

Room choices are limited to the user's branch and current clinical modality/device/room scope; unrestricted administrative roles retain their existing global access. Worklist queries are also branch-restricted, with missing branches returning no cases for non-global users. Existing clinical-scope query guards remain active. A stale saved room/device cannot reveal cases outside changed permissions.

Open now means: device and branch active, operational_status ACTIVE, inside device workday_start/end (including overnight shifts), no overlapping DeviceBlock, and no active BRANCH/DEVICE BookingBlock. It is evaluated on every request using the existing server-local naive scheduling convention. Appointment occupancy does not close a room; booking_enabled is a booking switch, not a clinical operational switch. There is no newly invented/manual room-open field and no equipment connectivity inference. Missing/invalid working-hour configuration fails closed. DeviceSchedule is a separate legacy slot-generation model; the current booking availability path uses device workday fields, which this filter follows. Other/procedure/staff-specific booking blocks do not close the entire room. No appointment/device setting is changed by these filters.

Shared template staff_worklist_filters.html renders EN/AR labeled controls and personal saved-view operations. technician_queue.py integrates filtering with existing waiting/in-progress/returned queries. app.py integrates nursing queries and expands the saved-filter whitelist/guards. No migration or new persistent infrastructure is required.
