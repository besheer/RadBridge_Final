RIS Web v5.8 Assignment Engine
================================
Keeps v5.7.2 Patient Safety and file upload protections.

Adds:
- Manual Assign / Reassign
- Auto Assign
- Doctor Take Case
- Unassigned Queue
- Case Priority: ROUTINE / URGENT / STAT
- Doctor Assignment Profiles:
  modalities, specialties, branches, max active cases,
  auto-assign on/off, availability, priority weight
- Workload balancing (lowest active case count first)
- Assignment audit history
- Auto assignment when a new order is created
- Doctor Workspace assignment controls
- Admin Assignment configuration page

No final report overwriting behavior is changed.
