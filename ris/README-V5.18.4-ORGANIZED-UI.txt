RIS Web v5.18.4 — Organized UI

Built on v5.18.3 and preserves the known clinical, PACS, booking, cashier/refund,
inventory/ERP, dictionary, profile and workflow functionality.

Key changes:
- One authoritative per-user Arabic/English language state.
- English = LTR with sidebar LEFT.
- Arabic = RTL with sidebar RIGHT.
- Old language route now updates UserProfile and both session language keys.
- Logical menu groups: Workflow, Clinical, PACS & Imaging, Finance, Management,
  System Administration, Personal Workspace.
- PACS Reconciliation placed inside PACS group.
- Cashier/Receivables/Accounting placed inside Finance.
- Booking availability/control placed under System Administration.
- My Ribbon and Ribbon Designer restored with permission-aware actions.
- Quick Ribbon shown in main workspace.
- User density/sidebar preferences applied to UI.
